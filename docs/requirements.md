# 拍立得记录需求基线

更新日期：2026 年 10 月 11 日 · v0.4

推活日记以日期为主线，记录和谁拍了多少张拍立得、花了多少钱。活动是可选的补充信息，用户不想填写时可以直接跳过，不需要先创建活动。

页面原型、交互和验收细节见 [PRD v0.4](PRD.md)。

## 已确认的需求

| 项目 | 需求 |
| --- | --- |
| 组织主线 | 主要展示日期，记录按日期回顾 |
| 活动 | 可填可不填，不与记录强绑定，不是保存前提 |
| 录入时机 | 现场随手记与事后统一补录都支持 |
| 核心统计 | 常规切数与特殊数量分开，实际花费统一汇总且不重复 |
| 记录对象 | 常规记录只归属一位偶像或一个团体；特殊 cheki 可关联多位偶像 |
| 类型 | 用户自己配置类型名称，每笔最多选一条；无固定分类 |
| 照片 | 上传可选；不上传也能完整使用记账与统计 |
| 相册 | 上传后可按日期、个人、团体或特殊 cheki 回顾 |
| 数据 | 支持完整备份、恢复与明细导出 |
| 代码仓库 | YihengBrianWu/cheki_record |
| 产品形态 | 小程序、App Store 应用或网页版后续决定 |

## 记录的最小单位

一笔记录独立保存日期、记录分类、关联对象、类型、张数与金额，活动及照片都可为空。一笔可包含多张同类拍立得，每笔最多选择一个自定义类型，无需逐张填表。

| 信息 | 规则 |
| --- | --- |
| 日期 | 必填，默认今天，可补录或修改 |
| 关联对象 | 常规只选一位偶像或一个团体；特殊 cheki 可选一位或多位参与偶像 |
| 张数 | 必填，正整数，默认 1 |
| 类型 | 选填且单选，用户自定义名称，例如 3寸、5寸、合照、单人、宿题、主题 |
| 实付金额 | 可暂时留空；明确免费填 0 |
| 活动 | 选填，可直接输入或选择已有名称，也可之后补充或清除 |
| 照片 | 选填，支持之后补充，不影响张数 |

不填写活动时直接保存为空，不自动生成「未命名活动」，不出现待补活动提醒。补充或移除活动不改变记录日期、金额和张数。

## 个人、团体与特殊 cheki

- 个人切：一笔只关联一位偶像，计入该偶像及全局常规切数。
- 团切：一笔只关联一个团体，计入该团体及全局常规切数，不分摊给成员。
- 特殊 cheki：独立分类，可关联多位偶像用于检索和回顾；数量单列，不进入全局常规切数、个人切数或团体切数。
- 所有分类共用同一份用户自定义类型，每笔最多选一条，团切与特殊 cheki 同样可配置类型。
- 数量口径已确认；金额暂按实际支出设计：特殊花费计入总花费并单独列出，不计入各参与偶像的个人花费，避免重复。这是当前产品建议，后续可调整。
- 「特殊」由用户选择，不从「合照」「双人」等类型名称自动判断。普通合照类型仍可归属一个对象。

## 自定义类型

每笔最多选择一条用户配置的类型。用户可以创建「3寸」「5寸」「合照」「单人」「宿题」「主题」，也可以直接创建「3寸合照」作为一条完整类型。产品不提供固定分类，不拆维度，不多选。类型可暂不填写；改名保留身份，删除类型不删除记录。

## 核心流程

- 现场：日期 → 个人 / 团体 / 特殊 → 类型、张数和金额 → 保存到当日记录。
- 事后：选择日期 → 连续添加个人、团体或特殊明细 → 核对本次新增合计 → 一次保存。
- 回顾：首页日期列表 → 当日记录 → 编辑、追加、补金额或补照片。
- 档案：个人、团体累计张数与花费 → 按日期排列的时间线 → 对应日期明细。

活动作为可展开的选填项。按日补录可给本次明细统一填活动，也可完全留空；已有当天记录保留，不覆盖。

## 统计规则

- 日期按记录的实际拍摄日计算，独立于创建时间和活动信息。
- 同一天的不同活动记录与无活动记录一起计入当天合计，明细保持独立。
- 首页、偶像档案和图表主要展示日期与有记录的天数，不将其称为场次数。
- 常规切数只汇总个人与团体记录的填写数量；特殊数量单列，两者都不等于上传照片数量。
- 金额缺失与 0 元分别保存；缺失记录计入张数，但花费显示为已记录金额并提示待补笔数。
- 支持单价计算与直接填写实付总额。修改张数时，固定单价可同步计算，手动总额需核对。
- 修改日期后，该笔移动到新日期及相应月份；其他记录与活动标签不受影响。
- 支持按日期范围、个人、团体、特殊参与偶像和类型查看；按特殊参与者筛选仅用于查找，不加入个人切数。活动可作为额外筛选，不是统计前提。

## 照片与数据保存

- 照片关联到独立记录，按该记录日期展示，无需活动。
- 上传、替换、删除照片都不改变张数或金额；允许一张照片拍下多张拍立得。
- 完整备份包含记录日期、分类、个人 / 团体对象、特殊参与者、类型、可选活动、照片和关联关系；建议使用带版本信息的 ZIP。
- 恢复前校验并预览，第一版建议整库替换；失败保留原数据，重复恢复不增加记录。
- CSV 包含日期、记录分类、对象类别、归属对象、特殊参与者、类型、张数、是否计入常规切数、金额、币种和可为空的活动列。金额未填导出为空，免费为 0。
- 原型仅演示备份恢复流程；正式数据持久化、离线和云端方案待平台确定。

## 待评审选择

- 类型已确定为用户自定义单选，不拆分固定维度。
- 特殊 cheki 的金额已按上述建议展示，评审时核对是否符合记账习惯。
- 是否需要账号、多设备同步及离线记录。
- 照片存储位置、原图策略和大小限制。
- 第一版建议默认人民币；如需多币种，则分别统计。
